# D팀 · 네이버 검색광고

팀원: 어메일 · 뚜벅 · 욤마
같이 풀 것: **키워드 → 문의 · 계약 판단**

팀원이 각자 만든 스킬 · 코드를 이 폴더에 올려요. 팀원도, 옆 팀도 가져다 써요.
데이터 연결(API)은 각자 해요. 같이 쓰는 건 데이터를 가져온 다음 단계예요.

올릴 때 폴더 하나에 `README.md` 4줄을 붙여요.
1. 무엇을 하나요
2. 무엇을 넣나요 (데이터 모양 · 가짜 샘플 파일)
3. 어떻게 돌리나요
4. 결과는 어떻게 나오나요 (캡처나 예시)

## 우리 팀 데이터 모양
11/4 조별 모임에서 정해요. 칸 이름 5~8개.
