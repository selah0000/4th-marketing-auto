## 대시보드 화면

![가상 데이터로 실행한 소재 성과 진단](2주차_셀라_1.png)

- 공개 시연의 금액은 기존 합성 샘플의 10배로 변경했습니다. 광고비 합계 2,340,000원, 방문당 비용 3,000원이며 실제 금액이 아닙니다.
- 모든 시연 수치는 가상입니다. 실제 광고·신청 데이터와 원본 주소는 캡처에 포함하지 않습니다.
- 로컬 시연: http://localhost:8042/?demo=1
- Vercel 공유 링크: https://selah-marketing-demo.vercel.app/

## 이번 주 완성한 탭

- 탭: **소재 성과 진단** — 개인 → 인스타 메뉴의 광고 성과·소재별 성과.
- 설계안 단계: 채널 성과를 모으고 광고 테스트 후보를 판단하는 단계.
- 공개 시연 코드: `workflows/셀라/public-demo/`. 위 Vercel 링크로 접속해 바로 실행할 수 있습니다.
- 입력: 1시간 자연 도달, 6시간 저장률·공유율·팔로우율.
- 실행: **진단 실행** → 공통 기준 v1.0으로 결과 계산 → 소재별 표시와 추천 TOP 3 갱신.
- 출처: 화면에 표시한 내장 합성 샘플 및 사용자 입력. 외부 API 실시간 조회 시연이 아닙니다.

## 1. 이번 주 한 것

- 브랜드와 서비스, 광고 성과, 신청·참여·상담, 결제·전환, 콘텐츠 아이디어, 운영 매뉴얼 구조를 구성했습니다.
- 광고 기간 필터, 소재 검색, 광고비·방문당 비용 정렬, 오가닉 유형 필터를 구현했습니다.
- 공통 기준표와 업데이트 일시를 매뉴얼에 기록했습니다.
- 가상 비교군 12건이라는 시연 조건을 명시하고, 입력값에 따라 광고추천 여부를 실제 코드로 계산합니다.
- 실제 광고 성과 TOP 3와 오가닉 테스트 후보 TOP 3를 구분했습니다.
- 실제 자료는 로컬 비공개 폴더에 유지하고 시연에서는 합성 데이터만 사용합니다.

### 시연 및 검증

1. 기본값(도달 1,400명 / 저장률 3% / 공유율 1% / 팔로우율 0.3%)에서 실행 → 광고추천.
2. 도달을 500명으로 변경 후 실행 → 기준 충족 전.
3. 입력을 비우고 실행 → 입력 오류 안내.
4. 소재 검색에 없는 제목 입력 → 검색 결과 없음.
5. 운영 매뉴얼 클릭 → 기준·계산식·예외·버전·업데이트 일시 확인.

## 2. 안 된 것

- 과거 콘텐츠의 1·6·24시간 실제 지표 및 비교군을 자동 수집하지 못했습니다. 실제 자료로 추천 검증은 아직 불가능합니다.
- 신청·상담·결제 연결, 광고 귀속 매출 및 ROAS, 일별 추이는 연결 전으로 표시합니다.
- 실제 썸네일 수집, 팀 로그인, 예약 실행, Slack 알림은 미완료입니다.
- 가상 자료로 판단 코드를 검증한 단계이며 광고 효율을 입증한 것은 아닙니다.
