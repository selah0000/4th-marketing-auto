# 2주차 · 대시보드 탭 1개 완성 (11/4 ~ 11/11)

마감: **11/10(화) 밤 · 11/11 싱크 전날**
설계안을 토대로 대시보드를 만들고, 탭 하나를 코드가 실제로 돌아가는 데까지 완성해요. 예: 소재 자동화라면 「경쟁사 서칭」 탭에서 검색하면 소재가 모이는 것까지.

## 개인 과제
이 폴더에 **내 이름 파일이 이미 있어요.** `2주차_닉네임.md`를 열어서 채우면 끝이에요.

### 탭 1개 완성 기준 (모두 해당)
- 입력할 수 있어요 (검색어, 원고, 기간 등)
- 실행하면 코드가 돌아서 허용된 데이터 소스에서 결과를 가져오거나 만들어요
- 결과와 출처가 대시보드에 보여요
- 결과가 없거나 오류가 나면 화면에서 알 수 있어요

정적인 가짜 결과만 보여주는 화면은 완성이 아니에요. API 접근이 어려우면 공개 URL을 넣어 정보를 가져오는 식의 **실제로 돌아가는 대체 방식**은 괜찮아요.

| 자동화 주제 | 첫 탭 예시 | 작동 기준 |
|---|---|---|
| Meta 성과 | 광고 성과 조회 | Meta API 조회 → 성과 표시 |
| Meta 판단 | 성과 진단 | 광고 데이터 처리 → 판단 근거 · 개선안 |
| Meta 소재 | 경쟁사 서칭 | 검색 → 소재 목록 · 출처 표시 |
| 네이버 | 키워드 성과 조회 | 데이터 조회 → 키워드별 성과 표시 |
| SNS 제작 | 카드뉴스 만들기 | 원고 입력 → 카드뉴스 초안 미리보기 |
| 멀티채널 | 채널 변환 | 원고 입력 → 채널별 초안 |
| 리포트 · 공유 | 데이터 모으기 | 실제 데이터 조회 → 요약 표시 |
