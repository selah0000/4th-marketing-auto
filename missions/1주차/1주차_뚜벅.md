# 1주차 · PRD + 단계별 자동화 설계안 | 뚜벅 (D팀)

마감: **11/4(수) 저녁 9시** · 1차 싱크 전

## 1. 한 줄 요약
고객사의 네이버 검색광고 성과와 예약 고객 내역을 받아서, **어떤 키워드가 실제 예약으로 이어졌는지 한 화면에서 보여 주고 오늘 할 일을 제안하는 대시보드**를 만들고 싶습니다.

## 2. 지금 하는 방식
- 순서: 네이버 광고 관리 화면에서 키워드 성과와 순위를 보고, 사이트 관리자 페이지에서 예약 고객을 따로 확인한 뒤, 둘을 맞춰 보며 키워드를 조정합니다.
- 주기와 걸리는 시간: 매일
- 해결하고 싶은 문제: 광고 성과와 예약 고객을 따로 봐야 해서, 어떤 키워드가 실제 예약으로 이어졌는지 한눈에 알기 어렵습니다.

## 3. 필요한 데이터
- 어디서 가져오나요?
  - 네이버 검색광고 키워드별 일별 성과와 평균 노출 순위: 처음에는 내보내기 파일로 시작하고, 이후 네이버 검색광고 API로 연결할 계획입니다.
  - 사이트 관리자 페이지의 예약 고객 내역: 내보내기 파일을 사용합니다. 유입 키워드(UTM)가 함께 남아 있어 광고 키워드와 연결할 수 있습니다.
- 권한이 있나요? 있음 (광고 계정 · API · 예약 내역 내보내기)
- 예약 고객 내역에는 개인정보가 있으므로, 이름과 연락처는 빼고 집계한 값만 사용할 계획입니다. 실제 데이터는 `private/`에만 두고, 저장소에는 가짜 샘플만 올리겠습니다.

## 4. 자동화 흐름
네이버 광고 관리 화면과 사이트 관리자 페이지를 오가지 않고, 대시보드를 열면 필요한 내용을 순서대로 볼 수 있게 만들 계획입니다. 메뉴 흐름은 ROY를 참고했습니다.

1. **광고 성과**: 키워드별 광고비 · 클릭 · CPC · 평균 노출 순위를 지난 기간과 비교해 보여 줍니다.
2. **실제 예약**: 예약 고객을 유입 키워드와 연결해 키워드별 예약 수와 예약당 광고비를 보여 줍니다.
3. **Insight**: 숫자를 근거로 잘되는 키워드와 비용만 쓰는 키워드를 짚어 줍니다.
4. **Action**: 오늘 할 일을 제안하면, 제가 승인 · 보류 · 반대로 답합니다.

계산은 프로그램이, 해석은 AI가 맡게 할 계획입니다. 같은 파일이면 언제 돌려도 같은 숫자가 나오도록 만들겠습니다.

## 5. 사람이 확인할 곳
- **연결되지 않은 예약**: 유입 키워드를 알 수 없는 예약은 「확인이 필요한 N건」으로 따로 보여 줄 계획입니다.
- **Action 제안**: 대시보드에서 광고 계정을 바꾸지는 않습니다. 승인한 내용만 제가 광고 관리 화면에서 직접 반영하겠습니다.
- **의료광고 표현**: 키워드나 문구를 바꿀 때는 규정을 먼저 확인하겠습니다.

## 6. 받고 싶은 결과물
대시보드 화면을 받고 싶습니다. 맨 위에 「오늘 볼 키워드 N개 · 확인이 필요한 N건」이 보이고, 그 아래 표에서 키워드 · 광고비 · 클릭 · 평균 노출 순위 · 예약 수 · 예약당 광고비와 제안을 함께 볼 수 있으면 좋겠습니다.

## 7. 단계별 자동화 설계안

| 단계 | 입력 | 하는 일 | 출력 | 도구 · 연결 | 대시보드 탭 이름 |
|---|---|---|---|---|---|
| 1 | 네이버 키워드 성과 파일 (이후 API) | 칸 이름을 맞추고 기간별로 비교 | 키워드 성과표 (평균 노출 순위 포함) | 기존 계산기(marketing_calc) · 네이버 검색광고 API | 광고 성과 |
| 2 | 키워드 성과표 + 예약 고객 내역 | 유입 키워드로 예약을 연결 | 키워드별 예약 수 · 예약당 광고비 | 계산기 + 연결 규칙 | 실제 예약 |
| 3 | 키워드별 예약 표 + 목표 예약당 광고비 | 근거 숫자를 붙여 잘되는 키워드와 안되는 키워드를 판단 | 판단 목록 | Claude Code + 계산기 | Insight |
| 4 | 판단 목록 | 「현재 → 제안 → 예상 영향 → 되돌리는 법」으로 정리 | 승인 · 보류 · 반대를 고를 제안 목록 | Claude Code | Action |
