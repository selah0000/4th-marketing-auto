# 1주차 · PRD + 단계별 자동화 설계안 | 어메일 (D팀)

마감: **11/4(수) 저녁 9시** · 1차 싱크 전

## 1. 한 줄 요약
네이버 · 구글 검색광고 키워드 성과와 노션에 쌓인 문의를 받아서, **제품군별 「광고비 → 클릭 → 문의」 흐름과 이번 주 끌 키워드 / 올릴 키워드 후보**를 만들어 나(광고 운영 담당)에게 주는 주간 대시보드예요.

> 산업용 안전설비 B2B 제조사에서 R&D와 마케팅을 같이 맡고 있어요. 검색광고는 제가 직접 보고 바로 조정해요.

## 2. 지금 하는 방식
- 순서: 네이버 검색광고 관리 화면에서 키워드 성과 확인 → 구글 Ads 따로 확인 → 노션 문의 DB를 훑어보며 어떤 제품 문의가 들어왔는지 확인 → 둘을 머릿속으로 맞춰 보고 입찰가 · 키워드를 조정
- 주기와 걸리는 시간: 매주 1~2시간
- 아쉬운 점: 두 매체를 따로 보고, 문의가 어떤 키워드로 들어왔는지는 일부만 알 수 있어요. 그래서 「돈은 쓰는데 문의가 안 나오는 키워드」를 감으로 고르고 있어요.

## 3. 필요한 데이터
| 데이터 | 어디서 | 권한 |
|---|---|---|
| 네이버 검색광고 키워드 성과 (노출 · 클릭 · 비용 · 전환) | 광고 관리 화면 보고서 다운로드(CSV · 엑셀) → 나중엔 검색광고 API | 확인 필요 |
| 구글 Ads 키워드 성과 | 보고서 다운로드(CSV) → 나중엔 Google Ads API | 확인 필요 |
| 문의 (홈페이지 문의 폼 · 자사몰) | 노션 문의 DB — CSV 내보내기 → 나중엔 노션 API | 보기 권한 있음 · API 연결은 확인 필요 |
| 제품군 목록 | 자사몰 카테고리 · 제품 카탈로그 (공개 자료) | 있음 |

- 전화 · 이메일 문의는 지금 기록이 안 돼서 이번 범위에서 빼요.
- 실제 데이터는 내 컴퓨터 `private/`에만 두고, 레포에는 가짜 샘플 데이터만 올려요.

## 4. 자동화 흐름
1. 매주 월요일 아침, 네이버 · 구글에서 지난주 키워드 보고서를 내려받아 `private/`에 넣어요.
2. 노션 문의 DB에서 지난주 문의를 가져와요.
3. 두 매체 성과를 같은 형식(키워드 · 매체 · 노출 · 클릭 · 비용 · 전환)으로 합쳐요.
4. 키워드를 제품군에 묶어요. 처음 한 번 표를 만들고, 그다음부터는 새 키워드만 더해요.
5. 문의 내용을 읽고 제품군 · 용도로 분류해요. 유입 경로를 알 수 있는 문의는 키워드까지 붙여요.
6. 제품군별로 광고비 · 클릭 · 문의 수 · 문의 1건당 광고비를 지난주와 비교해요.
7. 정해 둔 규칙으로 끌 후보 / 올릴 후보와 근거 숫자를 뽑아요.
   - 끌 후보(예): 광고비는 나가는데 그 제품군 문의가 2주 연속 0건인 키워드
   - 올릴 후보(예): 문의가 꾸준한 제품군인데 노출이나 클릭이 적은 키워드
   - 기준 숫자는 11/4 팀 모임 뒤에 정해요.
8. 내가 보고 승인 / 보류를 찍고, 승인한 것만 광고 관리 화면에서 직접 반영해요.

## 5. 사람이 확인할 곳
- **키워드 → 제품군 묶음:** 처음 만들 때 한 번 검수하고, 새 키워드가 생기면 그것만 확인해요.
- **문의 분류:** 제품군이 애매한 문의는 「확인 필요」로 표시하고 내가 골라요.
- **조정안:** 승인 / 보류는 내가 해요. 자동화가 광고 계정을 직접 바꾸지는 않아요.

## 6. 받고 싶은 결과물
내 컴퓨터에서 여는 대시보드(로컬 HTML) 하나에 탭 4개예요.

| 탭 | 보이는 것 |
|---|---|
| 키워드 성과 | 네이버 · 구글 합친 키워드 표. 매체 · 비용 · 클릭률로 정렬하고 걸러 보기 |
| 문의 분류 | 지난주 문의 목록 + 제품군 · 용도 · 유입 키워드(알 수 있는 것만) |
| 제품군 흐름 | 제품군별 광고비 → 클릭 → 문의 수 → 문의 1건당 광고비, 지난주 대비 증감 |
| 이번 주 조정안 | 끌 후보 / 올릴 후보 각 3~5개, 근거 숫자, 승인 · 보류 칸 |

맨 위에는 「이번 주 할 일 3개」를 한 줄씩 보여 줘요.

## 7. 단계별 자동화 설계안

| 단계 | 입력 | 하는 일 | 출력 | 도구 · 연결 | 대시보드 탭 이름 |
|---|---|---|---|---|---|
| 1 | 네이버 · 구글 키워드 보고서 파일 | 두 매체 형식을 맞춰 주간 성과표로 합치기 | 주간 키워드 성과표 | 보고서 다운로드(CSV) · Claude Code | 키워드 성과 |
| 2 | 노션 문의 DB (지난주) | 문의를 제품군 · 용도로 분류하고 유입 키워드 붙이기 | 문의 분류표 | 노션 CSV 내보내기 · Claude Code | 문의 분류 |
| 3 | 키워드 성과표 + 문의 분류표 + 키워드-제품군 묶음표 | 제품군별 광고비 · 클릭 · 문의 · 문의당 광고비, 지난주 비교 | 제품군 흐름표 | Claude Code | 제품군 흐름 |
| 4 | 제품군 흐름표 + 판단 규칙 | 끌 / 올릴 후보와 근거 뽑기, 승인 · 보류 기록 | 이번 주 조정안 | Claude Code · 로컬 대시보드 | 이번 주 조정안 |

**11/11에 완성할 첫 번째 탭:**
- 탭 이름: 키워드 성과
- 11/11에 실제로 되어야 하는 것: 네이버 · 구글에서 내려받은 지난주 키워드 보고서 2개를 `private/`에 넣고 명령 한 번 돌리면, 합쳐진 키워드 성과표가 대시보드 탭에 뜨고 매체 · 비용 · 클릭률로 정렬할 수 있어요.
