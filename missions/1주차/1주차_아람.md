# 1주차 · PRD + 단계별 자동화 설계안 | 아람 (F팀)

마감: **11/4(수) 저녁 9시** · 1차 싱크 전

## 1. 한 줄 요약
이미 돌아가는 **'글 하나 → 5채널 글(국문+영문) 발행'** 위에, **같은 원고로 카드뉴스·캐러셀(이미지 여러 장)과 릴스(세로 영상)까지 자동으로 만들어** 인스타·스레드·페이스북·링크드인·유튜브 쇼츠에 올릴 수 있는 상태로 나(그리고 앞으로 마케팅팀)에게 줍니다. 사람은 확인하고 발행 버튼만 누릅니다.

## 2. 지금 하는 방식
- **이미 되는 것 (3회차 과제에서 1차 완성):**
  1. 장면·원고 하나를 넣으면 브랜드 코어와 금지 표현 관문을 거쳐 원고(국문+영문)가 나온다
  2. 네이버·인스타·스레드·페이스북·링크드인용 글로 바뀌고 대표 이미지 1장이 붙는다
  3. 스레드·인스타는 API로 바로 발행, 나머지는 다 채워 두고 버튼만 사람이 누른다
- **안 되는 것 (이번 유닛에서 만들 것):**
  - 이미지가 **대표 이미지 1장뿐**이다. 카드뉴스·캐러셀(5~10장)은 만들어 본 적이 없다
  - **릴스·쇼츠 같은 세로 영상은 올려 본 적이 없다.** 디자인 툴·영상 편집을 손으로 배워야 해서 시작을 못 했다
- 주기와 걸리는 시간: 글은 **한 주에 3~7편** 발행 중. **카드뉴스와 릴스는 한 번도 만들어 본 적이 없다.** 손으로 배워서 만들기엔 시간이 안 나서, 처음부터 자동화로 만들고 싶다. 목표는 글이 나갈 때마다 카드뉴스·릴스가 같이 나가는 것 (한 주에 3~7세트)

## 3. 필요한 데이터
- 어디서 가져오나요?
  - **원고:** 이미 있는 멀티채널 원고(국문+영문)
  - **디자인 재료:** 브랜드 로고·색·글꼴, 제품 사진, 측정 장비·측정 화면 사진 (회사 자료)
  - **영상 재료:** 위 사진 + 카드뉴스 이미지, 저작권 없는 배경 음악, 자막(원고에서 자동)
  - **발행:** Instagram Graph API(캐러셀·릴스), Threads API(캐러셀), 링크드인(PDF 문서 캐러셀), YouTube(쇼츠)
- 권한이 있나요?
  - 인스타·스레드 API: **있음** (지금 글 발행에 쓰는 토큰. 캐러셀·릴스 발행 권한은 **확인 필요**, 영상은 공개 주소에 올려 둬야 함)
  - 링크드인·페이스북 자동 게시: **없음** → 지금처럼 다 채우고 버튼만 사람
  - 유튜브 쇼츠 업로드 API: **확인 필요**
  - 영상 만들기 도구(HTML → 영상, HyperFrames): **설치되어 있음**

## 4. 자동화 흐름
```
원고(이미 있음) ─▶ ① 카드 대본 ─▶ ② 카드뉴스·캐러셀 ─▶ ③ 릴스 ─▶ ④ 발행 대기 ─▶ ⑤ 성과
                  장별 문구 5~7장    이미지 1080×1350      같은 카드로 세로 영상   채널별 규격으로    반응 비교
                  (금지 표현 관문)    브랜드 템플릿          1080×1920 · 15~30초    사람은 버튼만      → 다음 카드
```
1. 이미 있는 원고를 **카드 대본**으로 쪼갠다: 1장 후킹 → 2장 문제 → 3~5장 측정해 보면 → 6장 해결 → 7장 행동 유도
2. 대본을 **브랜드 카드 템플릿**에 넣어 1080×1350 이미지 5~7장을 만든다 (국문·영문 두 세트)
3. 같은 카드를 장면으로 써서 **릴스(1080×1920, 15~30초)**를 만든다: 카드 넘김 + 자막 + 배경 음악
4. 채널별로 맞춘다: 인스타(캐러셀 + 릴스), 스레드(이미지 여러 장), 링크드인(PDF 캐러셀 · 영문), 페이스북, 유튜브 쇼츠
5. 미리보기 → 승인 → 발행 (API 되는 곳은 바로, 나머지는 버튼만)
6. 일주일 뒤 글만 올린 것 vs 카드뉴스 vs 릴스 반응을 비교해 다음 카드 주제에 반영한다

## 5. 사람이 확인할 곳
- **카드 대본:** 금지 표현(치료·효과 단정·과장)이 없는지, 숫자·사실이 맞는지
- **첫 장(후킹):** 피드에서 멈추게 하는지 — 사람이 최종 고르기 (후보 2~3개 중)
- **영상 미리보기:** 자막 오타, 장면 길이, 음악 저작권
- **발행 버튼:** 모든 채널에서 마지막 버튼은 사람
- **발행 뒤 확인:** 이미지 순서·잘림(인스타 4:5), 본문 깨짐

## 7. 단계별 자동화 설계안

| 단계 | 입력 | 하는 일 | 출력 | 도구 · 연결 | 대시보드 탭 이름 |
|---|---|---|---|---|---|
| 0 (있음) | 장면·원고 | 원고 다듬기 + 5채널 글 만들기 | 5채널 글 (국/영) | Claude Code, 콘텐츠 OS | 원고 |
| 1 | 원고 | 카드 대본으로 쪼개고 브랜드 템플릿에 넣어 이미지 만들기 | 카드뉴스·캐러셀 5~7장 (국/영) | Claude Code, HTML 카드 템플릿 → PNG | 카드뉴스 |
| 2 | 카드 이미지 + 대본 | 카드를 장면으로 세로 영상 만들기 (자막·음악) | 릴스 MP4 15~30초 | HyperFrames(HTML → 영상), FFmpeg | 릴스 |
| 3 | 카드·릴스·글 | 채널별 규격으로 맞추고 미리보기 → 승인 → 발행 | 발행 링크 / 버튼 대기 목록 | Instagram·Threads API, 링크드인 PDF, 유튜브 | 발행 큐 |
| 4 | 발행 링크 | 글 vs 카드뉴스 vs 릴스 반응 모으고 비교 | 성과표 + 다음 카드 주제 | Meta Insights API, 시트 | 성과 |

## 9. 팀과 겹칠 것, 도움받고 싶은 것
- **F팀(클레어 · 지지)과 겹칠 것:** 채널별 규격표(글자 수 · 이미지 비율 · 장수 · 영상 길이)를 하나로 만들어 `teams/F팀/`에 같이 쓰면 좋겠어요. 제 '글 → 5채널' 변환 규칙을 먼저 올릴 수 있어요.
- **E팀(원고 → 카드뉴스 · 검수)과 많이 겹쳐요:** 카드 템플릿과 검수 체크리스트를 같이 쓰거나 가져다 쓰고 싶어요.
- **도움받고 싶은 것:**
  - 인스타 캐러셀·릴스를 API로 발행해 보신 분 (영상 호스팅 방법 포함)
  - 첫 장 후킹 잘 뽑는 기준
  - 릴스 배경 음악 저작권 해결 방법
