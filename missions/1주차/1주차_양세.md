# 1주차 · PRD + 단계별 자동화 설계안 | 양세 (C팀)

마감: **11/4(수) 저녁 9시** · 1차 싱크 전

## 1. 한 줄 요약
관심 있는 업종이나 브랜드 이름을 넣으면, Meta 광고 라이브러리에서 지금 돌고 있는 광고 소재를 모으고 훅·컨셉·형식으로 분류해서 **「이 광고는 왜 이렇게 만들었나」 학습 노트와 내 콘텐츠 기획안**을 나에게 준다.

## 2. 지금 하는 방식
- 순서: 잘된 남의 영상·글을 직접 찾아본다 → 왜 떴는지 혼자 뜯어본다(아웃라이어뜯기 스킬) → 내 릴스·스레드·블로그 주제와 훅을 따로 짠다(훅카피 스킬)
- 주기와 걸리는 시간: 정해진 시간이 없다. 쉴 때 인스타를 자주 보면서 쓸 만한 걸 그때그때 가져오려고 한다. 광고 소재를 따로 찾아본 적은 없다.
- 아쉬운 점: 광고는 본 적이 거의 없다. 마케팅 비전공이라 「왜 이 광고가 이렇게 생겼는지」를 읽는 눈이 없다. 찾는 일과 기획하는 일이 끊겨 있다.

## 3. 필요한 데이터
- 어디서 가져오나요? **Meta 광고 라이브러리(공개 웹)** — 광고를 안 돌려도 누구나 볼 수 있다.
- 권한이 있나요? **필요 없음.** 단 공식 API(ads_archive)는 EU·영국 밖에선 정치·사회 이슈 광고만 돌려준다 → 한국 상업 광고는 **브라우저로 웹 화면을 읽어서** 모은다(C팀 공통으로 풀 문제).
- 내 쪽 데이터: 없음. 광고 집행을 안 하므로 성과 숫자 대신 「광고가 며칠째 돌고 있나(오래 돌면 잘되는 소재라는 신호)」를 쓴다.

## 4. 자동화 흐름
1. 업종 또는 브랜드 이름을 넣는다 (예: 숙소 예약, 다이어트 식품, 위스키)
2. 광고 라이브러리에서 한국 대상 · 지금 게재 중인 광고를 모은다 — 문구, 이미지/영상 첫 장면, 게재 시작일, 랜딩 링크
3. 오래 돌고 있는 순으로 정렬한다
4. 소재마다 훅(첫 문장·첫 장면) · 컨셉(무엇을 약속하나) · 형식(사진/영상/캐러셀) · CTA를 분류한다
5. 분류에서 **배울 것**을 뽑는다 — 이 업종은 어떤 훅을 많이 쓰나, 처음 보는 마케팅 개념(예: 소셜 프루프, 긴급성)을 쉬운 말로 설명
6. 배운 것을 내 채널(릴스·스레드·블로그 중 하나)에 옮긴 기획안 3개를 만든다

## 5. 사람이 확인할 곳
- 2번 뒤: 모인 광고가 내가 넣은 업종이 맞는지 (엉뚱한 브랜드가 섞였는지)
- 4번 뒤: 분류가 맞는지 샘플 몇 개 직접 본다
- 6번: 기획안은 그대로 올리지 않는다 — 고르고 고치는 건 내가 한다

## 6. 받고 싶은 결과물
- 소재 표: 브랜드 · 게재일수 · 훅 · 컨셉 · 형식 · CTA · 링크
- 학습 노트 한 장: 「이 업종 광고가 많이 쓰는 훅 TOP 3」, 「오늘 배운 마케팅 개념」
- 기획안 3개: 제목(훅) · 한 줄 내용 · 참고한 광고

## 7. 단계별 자동화 설계안

| 단계 | 입력 | 하는 일 | 출력 | 도구 · 연결 | 대시보드 탭 이름 |
|---|---|---|---|---|---|
| 1 | 업종·브랜드 이름 | 광고 라이브러리에서 게재 중 소재 모으기 | 소재 목록(문구·첫 장면·게재일·링크) | Meta 광고 라이브러리(웹) · 브라우저 자동화 | 소재 모으기 |
| 2 | 소재 목록 | 훅 · 컨셉 · 형식 · CTA 분류, 게재일수 순 정렬 | 분류표 | Claude Code | 소재 분석 |
| 3 | 분류표 | 업종별 패턴과 마케팅 개념 뽑기 | 학습 노트 | Claude Code | 배운 것 |
| 4 | 학습 노트 | 내 채널용 기획안 만들기 | 기획안 3개 | Claude Code · 훅카피 스킬 | 기획안 |

**11/11에 완성할 첫 번째 탭:**
- 탭 이름: 소재 모으기
- 11/11에 실제로 되어야 하는 것: 업종 이름 하나를 넣으면 한국 게재 중 광고 20개 이상이 표로 나온다 (문구 · 게재일 · 링크)

## 8. 3주 범위와 완성 기준
- 11/18까지 갈 곳: 1~2단계 — 모으고 분류까지
- 11/25에 "완성"이라고 말할 수 있는 상태: 업종 이름 하나로 4개 탭이 다 채워지고, 다른 업종으로 혼자 다시 돌릴 수 있다
- 이번에는 안 할 것: 광고 집행 · 성과 분석, 기획안 자동 발행, 영상 소재 내용 분석(첫 장면 캡처까지만)

## 9. 팀과 겹칠 것, 도움받고 싶은 것
- 겹칠 것: **1단계(광고 라이브러리 수집)는 C팀 공통 주제 그대로**다. 아리 · 찌니와 수집 코드를 같이 쓰고, 나는 뒤쪽(배운 것 · 기획안)을 다르게 가져가고 싶다.
- 도움받고 싶은 것: 마케팅 비전공이라 분류 기준(훅 · 컨셉 종류)을 실무에서 어떻게 나누는지. 광고를 돌리는 팀원이 보는 「잘된 소재」 기준.
