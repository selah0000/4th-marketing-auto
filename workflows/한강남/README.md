# 한강남 · 워크플로우 (G팀)

네이버 GFA 성과 + 상담 · 계약 기록 → 소재별 **상담 1건당 · 계약 1건당 비용**과 막힌 곳(소재 / 랜딩)을 보여 주는 대시보드입니다. 1주차 설계안의 1 · 2단계 탭('성과 가져오기' · '상담 붙이기') 시제품이에요.

## 하는 일
- GFA 보고서(날짜 · 캠페인 · 소재 · 노출 · 클릭 · 비용)와 상담 기록(날짜 · 채널 · 상태 · 소재)을 날짜 · 소재로 붙여요.
- 채널이 '네이버' / 'GFA'인 상담만 세고, 상태에 '계약'이 들어가면 계약으로 셉니다.
- 소재별 CTR · 상담당 · 계약당 비용을 계산하고, 막힌 곳을 표시해요. 소재 = CTR이 평균의 0.6배 미만, 랜딩 = 클릭 중 상담 2% 미만, 상담 2건 미만은 판단 보류예요.
- 상담 기록에 소재 칸이 없으면, 그날 클릭 비율로 나눈 **추정**이라고 표시해요.

## 무엇을 넣나요
- `sample/gfa_sample.csv`, `sample/consult_sample.csv` — **가짜 샘플**(7일 · 소재 3개)이에요.
- 열 이름은 '뜻'으로 찾기 때문에 조금 달라도 돼요. 이름 · 전화번호 같은 칸은 읽지 않아요.

## 실행 방법
```
python 상담붙이기.py                              # 샘플로
python 상담붙이기.py private/gfa.csv private/상담.csv   # 내 실제 파일 (private/는 안 올라감)
```
표준 라이브러리만 써서 설치할 것이 없어요. 결과는 `out/대시보드.html`이에요(올리지 않음).

## 결과
맨 위에 비용 · 클릭 · 상담 · 계약 · 상담당 · 계약당이 나오고, 아래에 소재별 표(계약당 비용 낮은 순 · 막힌 곳 · 근거)와 날짜별 표가 나와요.

## 필요한 것 (계정 · 권한 · 데이터)
- GFA 보고서 엑셀 내보내기(CSV로 저장) — 광고 계정 보기 권한
- 상담 기록에서 날짜 · 채널 · 상태 세 칸 (+ 소재를 남기면 더 정확)

> API 키 · 토큰 · 실제 데이터는 올리지 않아요. 실제 데이터는 `private/` 폴더에 두면 자동으로 안 올라가요.
