# 셀라 · 소재 성과 진단 과제 시연

모든 수치는 합성 샘플입니다. 실제 광고·신청·고객 자료, API 키, 인증 정보가 포함되지 않습니다.

## 실행

정적 웹 서버로 이 폴더를 제공하거나 Vercel에 배포합니다. 서버 함수·환경변수·외부 API가 필요하지 않습니다. 페이지는 항상 가상 데이터 모드로 실행됩니다.

## 시연

1. 도달 1400 / 저장률 3 / 공유율 1 / 팔로우율 0.3 입력 후 진단 실행 → 광고추천.
2. 도달을 500으로 변경 → 기준 충족 전.
3. 입력을 비우면 오류 표시. 없는 소재 검색 시 빈 결과 표시.
4. 운영 매뉴얼에서 1차 공통 기준과 업데이트 일시 확인.

비교군 12건 및 담당자 검토 완료는 시연을 위한 가상 조건입니다. 실제 성과 입증이나 자동 광고 집행 기능이 아닙니다.
